# Asset License Log

The MVP contains no redistributed third-party game art, fonts, music, or sound effects.

- Visuals: original procedural geometry, UGUI composition, and original generated advisor illustration atlas created for Lionrise.
- Font: Unity/runtime operating-system dynamic font fallback; no font file is redistributed.
- Music and SFX: generated at runtime by `CivicAudio.cs`.
- Text and card content: original project copy.

The private local reference export is used only for visual and behavioral measurement and is never copied into the player build.
